🔑 常见问题

  • 127.0.0.1:7890 是 Clash 等代理软件默认的 socks5 端口，可根据实际情况修改。
  • 如果提示 curl: (7) Failed to connect，请检查代理软件是否开启。
  • 每次修改 ~/.zshrc 后，都需要执行 source ~/.zshrc 让修改生效。
